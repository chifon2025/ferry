公開網址：<https://chifon2025.github.io/ferry/>。GitHub Pages 沿用原倉庫與網址；手机 PWA 的 id、scope、start_url 均保留。

## 首段試玩：一直沒開門的花店

人物與情節完全自創。小禾的花店準備開幕，訂好的花卻沒有送到。玩家選一張心願牌，選擇眼前的行動，翻開後續，再決定今天的安排。

- 心願 → 事件與行動 → 翻牌 → 新消息與調整 → 今天的後來。
- 三種初次行動與兩種開門安排，搭配兩種送貨時間；後續與行動相符，沒有好壞結局評分。
- 「一定要照原計畫才行」是一張可留在手邊或放到桌邊的心聲；可反覆切換，不影響事件、送貨時間或結局，也沒有放下判定。
- 送貨變化在本段開始時決定，與情緒、心願、心聲牌位置無關。「換一種走法」保留同一次外部情況，供比較不同選擇；不是反覆抽運氣。
- 人生故事與卡牌是原創，受萊斯特相關心法與主公描述的順流成真方向啟發，不宣稱改編其生平，不搬用自傳或課程原句，不保證願望成真或療癒效果。
- 手機直式優先，點選卡牌後再確認；純按鈕兼容觸控、鍵盤與輔助技術。內容可捲動與放大文字，尊重減少動態偏好。
- 首段沒有音樂、音效、水聲、倒數、分數、抽卡付費或帳號。

## 資料與離線

新進度僅使用 `du_ferry_cards_v1`，存於當前裝置。沒有後端或個資輸入，不讀寫旧遊戲存檔和聲音設定。

無法辨識的進度不覆寫，儲存空間失敗可繼續記憶體試玩；跨分頁衝突先提示讀取最新進度。每次確定選牌立即保存，更新後可接續。

`sw.js` 的 `cards-v1` 快取所有卡牌程式與插畫；只清除此站點的舊快取，不清 localStorage。舊 `boat.html`、`legacy.html` 保留回首頁的導覽，舊遊戲没有恢復。
