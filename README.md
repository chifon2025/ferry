# 渡 · 順流成真

## 正式玩法：520 個生活情境 × 豐盛釋放

公開網站：[渡](https://chifon2025.github.io/ferry/)。沿用既有 GitHub Pages、PWA 身分與手機安裝入口。首頁已正式取代舊的兩次行動選牌流程；原試玩網址 `reframe.html` 也開啟新版。

### 一件事，四個停點

1. **看見反應**：遇見生活情境，複選真的會冒出的內心話；都不像可略過。
2. **看見抓緊**：辨認反應下面「我很想得到」與「我很怕發生」的兩股力。
3. **鬆開一點**：目標與責任不丟，只鬆開「非得立刻照我想的不可」；還不能也沒關係。
4. **行動後放下**：選一個現實中能做的步驟，確認後看後續；做完，不用再靠反覆想催結果。

「照一照心裡」與「往後看看」保留在行動階段，可自由略過，不影響外部事件。反應組合不計分，也不改變同一行動的結果。沒有宗教測驗、配樂、水聲、倒數、付費抽卡、帳號或追蹤分析。

### 內容範圍與原創邊界

保留原本 25 類 × 每類 20 個事件的穩定 ID 與原始線索，再新增第 26 類「金錢壓力 · 20 則」，共 520 個不同生活情境。新內容涵蓋薪水延遲、減班、房租房貸、信用卡、周轉、客戶欠款、設備貸款、醫療費、家人支出、借款、投資虧損、想離職卻不敢等真實壓力。

全 520 則都使用同一個豐盛釋放核心：所選反應只照出此刻的內心話，不判定對錯；翻牌同時呈現想要與抗拒，再詢問能否先鬆開「非得立刻如此不可」。5 個試行情境與 20 則金錢壓力另有獨立手寫的情緒拉扯與內在想要。這套設計受《The Abundance Book》所述「豐盛不限金錢」與釋放阻力的高層觀念啟發，但所有遊戲情境與文案皆為原創，不重製書中文字或課程。

遊戲不把「釋放」設計成交換條件，也不宣稱放下就會得到錢、健康或關係結果。它練習的是：結果尚未改變時，先停止被匱乏、恐懼與控制欲推著走，再清楚處理數字、期限、溝通、安全與責任。

每個事件有 7 種非空反應組合或略過，再選 2 個行動，因此共有 8,320 條可完成的操作路徑；這是測試組合數，**不是 8,320 個不同結局**。不保證平靜會改變他人的回應或外部結果，亦非心理治療、醫療或財務建議。不要求放棄安全、責任與界線。

### 隨機、儲存與舊進度

- 全部或任一類別均優先抽取尚未遇見的事件；抽完重新洗牌，避免立刻重複上一件。切換類別只在按「換個情境」後生效，保留其他類別的已見紀錄。
- 右上選單可直接選「金錢壓力 · 20 則」。20 則走完前不重複，使用專屬內心戲與釋放停點，再回到數字、期限、正式窗口或可信任的人。
- 右上選單另有「釋放練習 · 5 則」，只在五個試行事件中輪抽，五則走完前不重複；用來直接比較新版，不必從全部情境裡碰運氣。
- 新進度使用 `du_ferry_flow_v1`。儲存情境 ID、類別、階段、已確認行動與已見 ID。第一次抽取即保存。
- **反應勾選只存在當頁記憶體，不儲存、不上傳。** 勾選或翻牌不寫入進度；此時重開回到同一情境的未勾選狀態。進入行動或收尾後重開，仍接續該階段。
- 第一次使用且尚無新存檔時，只讀取 `du_ferry_scenarios_v1` 作接續來源，不覆寫、不刪除。舊場景尚未行動者直接進入新流程；已選過行動或已到結尾者，保持原文字與已選分支，先完成該局，下一件事使用新玩法。必要的舊局資訊以 `legacy` 保存於新 key。
- 更早的 `du_ferry_light_v1`、`du_ferry_cards_v1`、`du_ferry_save_v1`、`du_ferry_audio_v2` 不讀寫、不清空。
- 新進度或待接續的舊進度損壞／格式未知時保留原樣，改為不寫入的暫時遊玩；儲存被封鎖或容量不足也可玩。新進度跨分頁發生衝突時，須讀取最新進度再繼續。

### 手機、安裝與離線

固定直式單屏，最大寬 480px，主畫面不向下捲動。安全區與 `visualViewport/innerHeight` 較小有效高度同步；底部操作固定成一區，閱讀區可收縮，長文以左右箭頭無損翻頁。選單可獨立捲動。轉向、回前景、字體載入及視窗尺寸變動重新計算；雙指放大不縮小版面。

沿用 SVG 山水、鏡面、村落與提燈。燈不是情緒分數，不會因為生氣而熄滅。安裝後直接開啟正式首頁，沒有獨立試玩 App。

Service worker `abundance-v1` 完整快取 17 個資源。首次連線完成快取後可離線重開、抽取與複選。所有站內導覽（含 reframe.html、boat.html、legacy.html）都由快取首頁接續當前進度；不攔截其他網站或其他專案路徑。保留選單檢查更新、回前景與重新連線時檢查。

### 程式與測試

純靜態，無需正式環境套件或外部 AI 服務：

```text
node tools/serve.js . 8138
node --test tests/*.test.cjs
```

- `scenario-seeds.js`：原 500 個事件保持穩定，尾端新增 20 個金錢壓力事件。
- `scenario-data.js`：事件組裝及 26 組現實行動內容。
- `scenario-core.js`：只為接續舊局載入；舊控制器 scenario.js 不在首頁執行。
- `reframe-core.js`：沿用五個原創試玩案例資料；舊試玩控制器 reframe.js 不在首頁執行。
- `flow-data.js`：26 組反應與轉念文字、五例試行及二十例金錢壓力的專屬內心戲與釋放停點。
- `flow-core.js`：想要／抗拒／鬆開核心、狀態轉移、均勻抽取、隱私化存檔投影、舊局接續。
- `flow.js`：正式介面、存檔衝突保護、功能選單與手機高度。
- `light.css`、`reframe.css`、`cards-layout.js`、`pwa-update.js`：共用排版、翻頁與更新。

測試覆蓋 520 事件的全部 8,320 組操作路徑、每則想要與抗拒的呈現、25 則專屬內心戲、五則試行與二十則金錢壓力各自一輪不重複、520 事件的略過／全選介面操作、全部舊事件分支接續、520 次抽取不重複、26 類篩選、反應不落地、損壞資料與跨頁衝突保護。
