# 渡

一天一局、約三分鐘的水墨渡口小遊戲。
把《順流成真》心法——相信真我、回歸平靜、做好當下、允許成真——玩出來，而不是讀出來。

## 玩法

- 每天開一局：霧散 → 昨日種下的因揭曉 → 做今日事 → 亂流抉擇（急的聲音 vs 靜的聲音）→ 吹燈
- 抉擇的後果一律**隔日揭曉**：有時如願，有時更好，偶爾落空但開另一扇門
- 今日局已開，可「靜坐片刻」（發呆 30 秒）再開一局
- 全程無數字、無分數——渡口的樣貌就是回饋（燈亮、茶棚、紅花、貓、小舟）
- 幾天沒來？缺席是留白：回來時霧散花開，棚下有旅人留的信
- 右上「音／默」鍵：禪風配樂與木魚點擊音（Web Audio 即時生成，零音檔），一鍵開關
- 「渡我一下」：不算局的 30 秒緊急法，現實中一急就按
- 夜渡：把現實卡住的事寫一句種進夜裡，隔日輕問「急還是靜」
- 旅人問渡：換你當靜的聲音，從字帖挑一句渡人，隔日收回信
- 三日連環事件、長卷（無數字成長軌跡）、今日隨身句
- 天色隨真實時辰、天氣每日一象（晴雲雨霧），雲漂雁過葦搖

## 工程

- 純靜態：`index.html` + `style.css` + `data.js` + `game.js`，零建置、零依賴、離線可玩
- 存檔：localStorage（本機，無帳號無後端）
- 手機直式單手；動畫極省，不發燙；尊重 prefers-reduced-motion

## 部署（GPT 負責）

根目錄即站點，GitHub Pages 直接指向 main 分支根目錄即可，無任何建置步驟。

- GitHub 倉庫：https://github.com/chifon2025/ferry
- 正式網站：https://chifon2025.github.io/ferry/

## 安裝成手機 App

- iPhone／iPad：用 Safari 開啟 Pages 網址，點「分享」→「加入主畫面」
- Android：用 Chrome 開啟 Pages 網址，點選單中的「安裝應用程式」或「加到主畫面」
- 安裝後以直式獨立視窗開啟；完成首次載入後可在離線狀態遊玩
- 更新離線資源時遞增 `sw.js` 內的 `CACHE_VERSION`；這只清舊快取，不會清除玩家的 `localStorage` 存檔
