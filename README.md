# 渡

一天一局、約三分鐘的水墨渡口小遊戲。
把《順流成真》心法——相信真我、回歸平靜、做好當下、允許成真——玩出來，而不是讀出來。

## 玩法

- 每天開一局：霧散 → 昨日種下的因揭曉 → 做今日事 → 亂流抉擇（急的聲音 vs 靜的聲音）→ 吹燈
- 抉擇的後果一律**隔日揭曉**：有時如願，有時更好，偶爾落空但開另一扇門
- 今日局已開，可「靜坐片刻」（發呆 30 秒）再開一局
- 全程無數字、無分數——渡口的樣貌就是回饋（燈亮、茶棚、紅花、貓、小舟）
- 幾天沒來？缺席是留白：回來時霧散花開，棚下有旅人留的信
- 右上「音／默」鍵：禪風配樂與木魚點擊音（Web Audio 即時生成，零音檔），一鍵開關

## 工程

- 純靜態：`index.html` + `style.css` + `data.js` + `game.js`，零建置、零依賴、離線可玩
- 存檔：localStorage（本機，無帳號無後端）
- 手機直式單手；動畫極省，不發燙；尊重 prefers-reduced-motion
