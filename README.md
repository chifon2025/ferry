# 渡 · 順流成真

## 正式玩法：500 個生活情境 × 複選轉念

公開網站：[渡](https://chifon2025.github.io/ferry/)。沿用既有 GitHub Pages、PWA 身分與手機安裝入口。首頁已正式取代舊的兩次行動選牌流程；原試玩網址 `reframe.html` 也開啟新版。

### 一件事，三個步驟

1. 遇見生活情境，勾選像自己的第一反應。可複選，再點可取消；都不像可略過。
2. 按「翻牌看看」，逐一閱讀所選反應的另一個角度。「調整選擇」保留勾選；無須答對或立刻平靜。
3. 選一個具體做法，先預覽、再確認，看到後續後收尾。可以再遇見一件事、重玩，或先停下。

「照一照心裡」與「往後看看」保留在行動階段，可自由略過，不影響外部事件。反應組合不計分，也不改變同一行動的結果。沒有宗教測驗、配樂、水聲、倒數、付費抽卡、帳號或追蹤分析。

### 內容範圍與原創邊界

保留原本 25 類 × 每類 20 個事件，共 500 個不同標題、生活處境與事實線索；穩定 ID 與原始線索不變。500 個開場是短生活片刻，包含對話、動作、物件和心裡冒出的話。

新增 25 組主題相關的第一反應與轉念文字，每組三句；相同主題共用這組文字，**不是 500 套全新獨立手寫劇本**。先選 5 個事件（s041、s003、s201、s096、s131）試行較接近萊斯特釋放思路的停點：不急著改念頭，先容許感受，看看是否抓緊肯定、控制或安心，再問自己願不願意鬆開一點；「還不願意」也是可接受的答案。其餘 495 個事件維持原本的翻牌轉念，方便直接比較。原 5 個事件同時保留專屬反應與行動，其餘事件使用該類原有的兩個起始行動及對應後續，帶入各自事實線索；不再要求選第二輪後續牌。

每個事件有 7 種非空反應組合或略過，再選 2 個行動，因此共有 8,000 條可完成的操作路徑；這是測試組合數，**不是 8,000 個不同結局**。不保證平靜會改變他人的回應或外部結果，亦非心理治療、醫療或財務建議。不要求放棄安全、責任與界線。

### 隨機、儲存與舊進度

- 全部或任一類別均優先抽取尚未遇見的事件；抽完重新洗牌，避免立刻重複上一件。切換類別只在按「換個情境」後生效，保留其他類別的已見紀錄。
- 右上選單另有「釋放練習 · 5 則」，只在五個試行事件中輪抽，五則走完前不重複；用來直接比較新版，不必從 500 則裡碰運氣。
- 新進度使用 `du_ferry_flow_v1`。儲存情境 ID、類別、階段、已確認行動與已見 ID。第一次抽取即保存。
- **反應勾選只存在當頁記憶體，不儲存、不上傳。** 勾選或翻牌不寫入進度；此時重開回到同一情境的未勾選狀態。進入行動或收尾後重開，仍接續該階段。
- 第一次使用且尚無新存檔時，只讀取 `du_ferry_scenarios_v1` 作接續來源，不覆寫、不刪除。舊場景尚未行動者直接進入新流程；已選過行動或已到結尾者，保持原文字與已選分支，先完成該局，下一件事使用新玩法。必要的舊局資訊以 `legacy` 保存於新 key。
- 更早的 `du_ferry_light_v1`、`du_ferry_cards_v1`、`du_ferry_save_v1`、`du_ferry_audio_v2` 不讀寫、不清空。
- 新進度或待接續的舊進度損壞／格式未知時保留原樣，改為不寫入的暫時遊玩；儲存被封鎖或容量不足也可玩。新進度跨分頁發生衝突時，須讀取最新進度再繼續。

### 手機、安裝與離線

固定直式單屏，最大寬 480px，主畫面不向下捲動。安全區與 `visualViewport/innerHeight` 較小有效高度同步；底部操作固定成一區，閱讀區可收縮，長文以左右箭頭無損翻頁。選單可獨立捲動。轉向、回前景、字體載入及視窗尺寸變動重新計算；雙指放大不縮小版面。

沿用 SVG 山水、鏡面、村落與提燈。燈不是情緒分數，不會因為生氣而熄滅。安裝後直接開啟正式首頁，沒有獨立試玩 App。

Service worker `scenarios-v7` 完整快取 17 個資源。首次連線完成快取後可離線重開、抽取與複選。所有站內導覽（含 reframe.html、boat.html、legacy.html）都由快取首頁接續當前進度；不攔截其他網站或其他專案路徑。保留選單檢查更新、回前景與重新連線時檢查。

### 程式與測試

純靜態，無需正式環境套件或外部 AI 服務：

```text
node tools/serve.js . 8138
node --test tests/*.test.cjs
```

- `scenario-seeds.js`：500 個事件原文、穩定順序與事實線索，不任意重排。
- `scenario-data.js`：既有事件組裝及 25 組行動內容。
- `scenario-core.js`：只為接續舊局載入；舊控制器 scenario.js 不在首頁執行。
- `reframe-core.js`：沿用五個原創試玩案例資料；舊試玩控制器 reframe.js 不在首頁執行。
- `flow-data.js`：25 組反應與轉念文字、五例專屬反應／行動與釋放停點、全 500 事件的新行動資料。
- `flow-core.js`：新狀態轉移、均勻抽取、隱私化存檔投影、舊局接續。
- `flow.js`：正式介面、存檔衝突保護、功能選單與手機高度。
- `light.css`、`reframe.css`、`cards-layout.js`、`pwa-update.js`：共用排版、翻頁與更新。

90 項單元／介面回歸測試通過。新增測試覆蓋 500 事件的全部 8,000 組操作路徑、五則釋放停點與其餘 495 則的隔離、專用五則篩選與一輪不重複、500 事件各自的略過／全選介面操作、全部舊事件分支接續、500 次抽取不重複、25 類篩選、反應不落地、損壞資料與跨頁衝突保護。

新版無頭 Edge 驗證工具（需 Playwright，可設定 FERRY_PLAYWRIGHT_PATH）：

```text
node tools/flow-browser-check.cjs
node tools/flow-update-check.cjs
node tools/release-five-check.cjs
```

第一個工具通過 1,000 個排版／互動狀態、800 頁翻牌文字檢查，涵蓋 25 類、手機／橫式／200% 字體、逐頁完整呈現多選反應、離線與舊入口；第二個工具在隔離的本機服務實際模擬 scenarios-v4 已安裝版本升級，確認舊局接續、舊原始紀錄不變與新版離線遊玩；第三個工具專門驗證五則釋放停點在 320×568、390×844 與離線模式中完整翻頁、不儲存反應。這些是瀏覽器模擬，**不是實體手機安裝驗收或習慣養成成效證明**。

舊版測試使用 `tests/fixtures/scenario-v1.html` 與 `tests/fixtures/reframe-pilot.html` 驗證歷史控制器，未停用歷史回歸測試。舊 scenario-* / reframe-* 瀏覽器工具針對歷史版本保留，不作為現行首頁的驗證指令。
