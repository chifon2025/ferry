公開網址：<https://chifon2025.github.io/ferry/>。GitHub Pages 沿用原倉庫與網址；手機 PWA 的 id、scope、start_url 均保留。

## 十五段花店日記

人物與情節完全自創。小禾的花店準備開幕，訂好的花卻沒有送到。玩家選一張心願牌，選擇眼前的行動，翻開後續，再決定今天的安排。

1. **一直沒開門的花店**：面對到貨延誤，九條行動路線。
2. **一句不好看的評語**：面對客人的負評，三種初次行動、各兩種回應，共六條路線。
3. **不想錯過的訂單**：面對明早二十束花的詢問，三種初次行動、各兩種回應，共六條路線。

4. **抽屜裡的兩個信封**：金錢與安全。
5. **一直沒有亮起的訊息**：關係與期待。
6. **關燈後還在開的店**：反覆擔心。
7. **寫錯名字的卡片**：責任與自責。
8. **午餐旁邊的花剪**：照顧自己。
9. **街角的新招牌**：比較與自傲。
10. **還沒拆開的帳單**：付出與匱乏。
11. **電話裡的那句老話**：舊關係與認同。
12. **送出去之後**：給予、接收與界線。
13. **四個空位的小聚**：心願與行動。
14. **連平靜都想趕快做好**：對放下的執著。
15. **沒有大事發生的一天**：滿足與日常。

十二段新故事各有兩種初次行動，每種有兩種後續，共新增四十八條路線；加上前三章共六十九條行動路線。每條有自己的後續和結尾，不用同一個結局假裝分支。新章不靠隨機決定結果，也不預設之前選了特定結局。

結尾可進下一章或重玩當章；功能選單可任選十五章，不需解鎖，須點「開始這章」才取代目前進度。新資料在 `cards-journey.js`，原三章的分支與存檔保持相容。

- 心願 → 事件與行動 → 翻牌 → 新消息與調整 → 今天的後來。
- 三種初次行動，各有三張專屬後續牌：問清楚 → 接預約／改約／取花；借枝葉 → 做葉束／養好枝葉／邀鄰居佈置；發消息 → 回覆急用花的人／通知改期／邀人來看看。搭配兩種送貨時間，共九條行動路線、十八種情境結尾；三張心願不改變外部結果。
- 新消息會留下手邊的線索，選牌後先顯示可能的取捨，再由玩家確認。結尾呈現具體後果與走過的兩張行動牌，沒有好壞結局評分。
- 每章加入獨有的「想要／不想要」雙面內心卡：看見想抓住的 → 看見想推開的 → 自己看看有沒有變化。兩面都可選「試著鬆一點」「現在還不行」或離開；最後可答「有鬆一點」「還是一樣」「先到這裡」，不要求正面回報。不記錄內心選擇，不改變故事結果。
- 內心卡使用同一個固定閱讀區和手牌區，無新增長捲頁；「回故事」恢復原本尚未確認的行動。可在行動、待翻牌、回應階段打開；在待翻牌階段離開會回到原牌背。重開只捨棄這次尚未完成的內心體驗，接續已保存的故事。
- 每個結尾有一個屬於該情境的「帶回日常」提示；沒有分數、連續簽到、情緒偵測、成功判定或提醒推播。
- 送貨變化在本段開始時決定，與情緒、心願、心聲牌位置無關。「換一種走法」保留同一次外部情況，供比較不同選擇；不是反覆抽運氣。
- 人生故事與卡牌是原創，受已讀《豐盛之書》觀念與主公描述的方向啟發；不宣稱改編生平、熟讀所有正文或完整重製課程。沒有搬用書中人物、案例、量表、極端想像題或原文，也不納入疾病自癒、財富必然顯化等保證。可保留必要的安全、醫療協助、經營安排與人際界線。[研究範圍與主題對照](RESEARCH.md)。
- 手機直式優先，比照《主公我來了》的手機外框：最大寬 480px、高度 100dvh、固定 body，不捲動整頁。長文依閱讀區實際容量分頁，不縮字或省略結尾；縮放字體與可見高度變動時重新分頁。點牌在同一閱讀區看詳情，「回故事」不丟棄選牌，底部確認按鈕固定可用。功能選單本身可捲動。
- 首段沒有音樂、音效、水聲、倒數、分數、抽卡付費或帳號。

## 往後看看 · 時間卡

靈感來自使用者自己的經驗：「十年之後，這件事還會在我心裡嗎？」不是引自書中練習。選好心願後，可以點時間卡，先看該章獨有的「過些日子」原創想像，再問十年之後。十五個片刻皆非預告，不透露未翻開的後續，不推進故事時間。

可答「也許會淡一些」「可能仍會在意」「先不回答」，也可隨時回故事。仍在意的答案承認長期影響，不否定困難；不保證恢復平靜。兩種探索共用固定閱讀區，入口並排，不加長手機畫面。探索中兩個入口都可直接回故事，恢復未確認的行動；時間卡不保存答案、不改變結果，跨分頁保護沿用原機制。

## 資料與離線

新進度僅使用 `du_ferry_cards_v1`，存於當前裝置。沒有後端或個資輸入，不讀寫旧遊戲存檔和聲音設定。

無法辨識的進度不覆寫，儲存空間失敗可繼續記憶體試玩；跨分頁衝突先提示讀取最新進度。每次確定選牌立即保存，更新後可接續。

進度格式仍為 `v:1`，新故事加上 `edition:2`。未帶 edition 的原卡牌進度會沿用原本的兩張後續牌與原結尾，載入不改寫資料；在結尾按「換一種走法」才進入加強版，保留相同到貨情境。未知版次進入不覆寫原資料的暫時試玩。

後續章節使用穩定的 `chapter` 識別值（從 `review`、`order` 延伸至 `ordinary`）；缺少 chapter 的舊進度仍是第一章。閱讀頁碼、內心卡回答與尚未確認的選牌只留在記憶體；重開接續已確認階段，從該階段第一頁閱讀。舊 `aside` 欄位仍可讀，僅為相容保留，新介面不再將它當作情緒或放下狀態。

`sw.js` 的 `cards-v6` 快取所有卡牌程式與插畫，包含新日記、時間卡、章節資料與分頁模組；只清除此站點的舊快取，不清 localStorage。舊 `boat.html`、`legacy.html` 保留回首頁的導覽，舊遊戲沒有恢復。來源書檔未放進專案、快取或發布內容。
