# 渡 · 順流成真

## 遇見生活：500 種隨機情境

公開網站：[渡](https://chifon2025.github.io/ferry/)。沿用既有 GitHub Pages、PWA 身分與安裝入口。

取消固定主角、十二章人生主線、序章與尾聲。每次隨機遇見一件生活事件，維持原有按鍵與手機固定畫面。無需登入、付費抽卡或外部 AI 服務。

### 內容與玩法

25 類 × 每類 20 個原創事件，共 500 個不同的標題、處境與事實線索；不是 500 個章節，也不是把同一句話換編號。涵蓋等待、變動、批評、誤會、界線、忙碌、失誤、比較、支出、未知、訊息、家庭、合作、遺失、休息、目標、幫助、受助、完美要求、網路、日常不順、公平、轉變、陪伴與平凡生活。

每類共用一組針對該主題設計的回應路線，而非 500 套各自完整手寫的分支劇本。每個事件有兩張行動牌，各接兩張後續牌，組合為 2,000 條可完成的情境路線。結果描述由選擇與當次情境線索組成，不保證外界因情緒平靜就改變。

- 點牌預覽做法，按確認才推進；每次兩次選擇後收尾。
- 「照一照心裡」看見想要與不想要；「往後看看」保留十年視角。都可略過，返回保留待確認的牌，不記錄感受。
- 收尾可「再遇見一件事」、「換一種走法」或「先停在這裡」。
- 右上功能選單可選全部或任一類別，按「換個情境」才取代目前這一件。
- 沒有分數、連續登入、集滿要求、情緒評級、配樂、水聲或倒數。
- 非宗教測驗、心理治療或專業建議；不要求放棄醫療、安全、責任與界線。

### 生活感文字改寫

500 個開場全部改寫為短生活片刻，加入對話、動作、具體物件和想說未說的念頭，單篇開場約 35–55 字。50 段類別共用後續改為較口語的反應；收尾先呈現所選的實際做法，不再只重述牌名。沒有改回連續故事，也沒有增加操作步驟或強制情緒練習。

內容更新保留所有情境 ID／標題、原始事實線索、行動與回覆 ID，並以 500 筆身分指紋回歸測試防止意外錯位；現有存檔直接接續。不新增追蹤、外部內容服務或音訊。另用實際瀏覽器在 320×568 逐一驗證全部 500 個開場，可無損翻頁、確認鍵可見，目前最多兩頁。

### 隨機與存檔

同一輪從未遇見的情境均勻抽取，不重複直到該範圍抽完；抽完重新洗牌，避免立刻又抽中上一件。選特定類別抽完時只重設該類的已見紀錄，其他類保留；因此切換類別後，已重新洗牌的類別可能再次出現。抽取範圍、已見清單和目前階段一起保存。

新 key 為 `du_ferry_scenarios_v1`，v:1。第一次抽取立即保存，尚未按牌就重開也會回到同一件事。只記錄情境 ID、類別、階段、已確認選擇與已見 ID，不記錄玩家的情緒或文字輸入。

舊版 `du_ferry_light_v1`、`du_ferry_cards_v1`、`du_ferry_save_v1`、`du_ferry_audio_v2` 不讀寫、不覆寫、不清空。未知版本、損壞或不完整的新存檔保留原樣，提示本次暫時試玩。儲存失效／容量不足仍可玩。跨分頁有衝突時需先讀取最新進度，避免覆蓋另一頁。

### 手機、安裝與離線

保留固定直式單屏，最大寬 480px，安全區與 visualViewport/innerHeight 較小有效高度同步。底部操作固定成一區，閱讀區可收縮；長文無損分頁，不需要向下捲動主畫面。功能選單可獨立捲動。縮放、轉向與回前景仍重新計算；雙指放大不縮成更小版面。

沿用程式原生 SVG 山水、鏡面、村落與提燈，五種景色隨情境類別切換；燈不是分數，也不會因情緒而熄滅。

Service worker `scenarios-v2` 完整快取 13 個資源（包含 500 個情境），支援第一次連線完成快取後離線重開與繼續抽取。安裝 App、選單檢查更新、回前景與重新連線檢查保留。舊入口 boat.html、legacy.html 仍開啟目前情境。舊章節模組保留作歷史回歸測試，不載入現行首頁、不納入離線快取。

### 開發與驗證

純靜態，無需建置或正式執行相依：

```text
node tools/serve.js . 8138
node --test tests/*.test.cjs
```

- `scenario-seeds.js`：500 個事件與情境線索，穩定 ID 依現有順序產生；後續編輯不得任意重排。
- `scenario-data.js`：25 組回應路線、鏡子／帶回日常內容與組裝。
- `scenario-core.js`：純狀態轉移、抽取、類別、存檔驗證。
- `scenario.js`：介面、儲存、功能選單；沿用 `light.css`、`cards-layout.js`、`pwa-update.js`。

單元與介面模擬測試涵蓋所有 500 個情境、2,000 條路線、500 次無重複抽取、類別輪替、重開、無效資料、存檔衝突和四種舊紀錄保護。選用的無頭 Edge 檢查：

```text
node tools/scenario-browser-check.cjs
node tools/scenario-mobile-check.cjs
node tools/scenario-offline-check.cjs
node tools/scenario-update-check.cjs
node tools/scenario-content-update-check.cjs
node tools/scenario-reading-check.cjs
```

需已安裝 Playwright，可透過 FERRY_PLAYWRIGHT_PATH 指定位置。本版 70 項單元／介面回歸測試通過；瀏覽器工具完成 1,202 項檢查，涵蓋 25 類、三階段、選牌預覽、鏡子、十年視角、手機尺寸及 150%／200% 字體；手機工具通過 60 個觸控與可見高度狀態；離線工具驗證實際快取、離線重載、繼續抽取及舊資料保護。更新工具以隔離的本機服務分別模擬 light-v2 故事版與 scenarios-v1 情境版升級，確認新版自動重載、正在玩的情境與舊存檔保留、快取汰換及離線抽取。這些是瀏覽器模擬，**不是實體 iPhone／Android 安裝驗收或使用成效證明**。
