# 渡

手機直式、免帳號的渡口日常小遊戲。
看見心裡想要的一刻，放一盞河燈，再回到眼前的生活。不評分、不限制每天次數，也不保證願望成真。

## 河一直在流 · 手機場景版

- 首頁兩個入口：「心裡有件事」與「到渡口走走」。
- 直式手繪水岸、茶棚、信匣、渡船、船家與小貓；場景熱點可點，主要操作留在底部。
- 核心：看見（文字可留白）→ 心裡展開 → 拖曳鬆手或輕點放燈 → 可選喝茶／問候／坐下 → 回到今天。
- 三段短故事：等信、順路請託、空著的渡船；沒有正確答案或心境測驗。完成相遇後，隔日信匣留下普通的生活後續，不把好結果當獎勵。
- 心願只暫存在本機以便續接，結束這一趟後移除；只有主動留下的隨手記收進小冊。
- 字帖、信匣、舊日長卷、原版故事與生活紀錄都收進「渡口小冊」，不刪舊資料。
- 桌機沿用同一個最大 520px 的直式介面；表單使用 16px 字、可捲動底部面板、安全區留白與可見視窗高度適配。
- 詳細設計與測試界線：[手機場景版設計.md](手機場景版設計.md)。原創圖像與生成提示：[art/README.md](art/README.md)。

## 保留的日常體悟版玩法（小冊 → 接續原版故事）

- 三段完整原創故事：等不到回覆、幫忙與界線、努力卻未如願；每段三條行動分支。
- 今日故事：察覺 → 探索眼前線索 → 選擇具體行動 → 完成動作 → 容許未定結果 → 自願帶一步回生活。
- 每頁固定顯示「情境與線索 → 選下一步 → 做出行動 → 看看結果 → 回到生活」，並明寫當前操作目標；合併過細的結果頁，避免只為翻頁而點擊。
- 正式故事的後續隔日到信匣；不保證選得平靜就會成功。
- 「自由試玩」隨時能玩全部故事及後續，不計入每日正式進度，也不用等倒數。
- 「留給生活」可記情境和一小步；忘了、沒遇到、仍未解決都不扣分，不再給金點。
- 不設答對獎勵、連續登入、排行榜或強迫補進度。
- 右上「⚙ 功能」面板：集中管理新版聲音與安裝手機 App。
- 「渡我一下」：不計局、不用等待，帶著此刻的感受看事實、選下一步。
- 原本的字帖、來信、夜渡、生活扳機、長卷與場景裝飾保留；未完的舊連環故事可接續。
- 舊內容僅作相容入口，不再生成新的舊版事件或啟動平靜評分機制。
- 天色隨真實時辰、天氣每日一象（晴雲雨霧），雲漂雁過葦搖

## 工程

### 水岸聲景

- `sound-core.js` 是原創 Web Audio 合成音色，`audio.js` 負責手勢啟動、音量偏好、場景與背景暫停。沒有外部音檔、錄音素材或連線需求。
- 河水與風聲鋪底，短琴音主題有三個相關變化，樂句之間留白；放燈後配樂退開，不播放勝利／達成音。
- 依玩家試聽回饋，下修水聲／風聲的源音量與高頻沙沙聲；既有玩家的音量滑桿不被改寫，也會得到較安靜的背景聲。
- 信匣木蓋與紙張、倒茶與杯聲、河燈碰水、落座衣物等各有動作音效；普通按鈕改為更輕的觸碰聲。
- 功能 →「調整聲音」分開控制配樂、環境聲、操作音效；「只聽河聲」關閉琴音、風聲與操作音，切回「水岸與琴音」保留自訂音量。
- 沿用 `du_ferry_sound` 總開關，兼容 `0`／`off`／`false` 舊靜音值。獨立音量存於 `du_ferry_audio_v2`，不改玩家遊戲存檔；設定儲存失敗會提示。
- 背景分頁暫停 AudioContext 與排程，總靜音淡出後暫停；新玩法不啟動舊版選用的耳機雙耳音。
- 合成波形測試確認有輸出、未削波、總靜音為零、放燈後琴音降低；這不是實體手機喇叭或耳機的主觀聽感驗收。

### 存檔與執行

- 純靜態：`river-core.js` 管理新旅程，`river.js`／`river.css` 呈現手機場景；保留原有 `practice-*` 與音樂。零建置、零執行依賴。
- 存檔沿用 `du_ferry_save_v1`。升級前備份為 `du_ferry_save_v1_before_daily_v1`，新進度放在 `dailyPractice`。
- 手機場景版只新增 `riverJourney` 欄位；原有所有欄位與音效設定不變。既有旅程可從「接著這一趟」續玩。
- 每個故事階段與生活邀請草稿即時儲存；無法儲存時停止前進並提示，不默默吞錯。跨分頁異動會暫停寫入，避免互相覆蓋。
- 存檔只在這個瀏覽器，無帳號／雲端同步；清除瀏覽器資料會遺失。設定頁提供 JSON 匯出，尚未提供匯入介面。
- 手機直式單手；少量 CSS 動畫，背景分頁暫停，尊重 prefers-reduced-motion；未做實體裝置耗電／溫度量測。

## 安裝成手機 App

- 右上角固定「⚙ 功能」鍵；音樂音效與安裝手機 App 都收在同一面板，比照《主公我來了》的操作方式。
- iPhone／iPad：用 Safari 開啟 Pages 網址，點「⚙ 功能」→「安裝手機 App」，照著「分享」→「加入主畫面」→「以網頁 App 打開」→「加入」。
- Android：用 Chrome 開啟 Pages 網址，點「⚙ 功能」→「安裝手機 App」；支援安裝提示時直接叫出系統安裝視窗，否則顯示瀏覽器選單步驟。
- Manifest 宣告直式獨立視窗；實際方向鎖定依手機／瀏覽器支援。首次完整快取後可離線遊玩，包含背景和角色。
- 更新離線資源時遞增 `sw.js` 內的版本尾碼。只清本遊戲快取，不清存檔或其他網站的快取。
- 開啟、回到前景與重新連線時主動檢查更新；功能面板也提供「檢查更新」。完整下載成功後直接接手，無須等待其他分頁關閉。
- 有未離開的文字表單或存檔錯誤時先提示，完成填寫後再套用；故事更新後接回原階段。首次從舊版遷移會重新載入，已保存進度保留。
- 離線或下載失敗時繼續用原版。不要清除網站資料來更新。

## 驗證與本機預覽

```powershell
node --test tests/practice.test.cjs
node --test tests/river.test.cjs
node --test tests/sound.test.cjs
node tests/river.browser.cjs
node tests/sound.browser.cjs
node tests/pwa-update.browser.cjs
node tools/serve.js . 8137
```

瀏覽 `http://127.0.0.1:8137/`。本機預設不安裝 Service Worker；需要驗證離線時用獨立測試埠並加 `?offline-test=1`。
瀏覽器測試需在 NODE_PATH 提供 Playwright，使用隔離的無頭 Edge 設定檔。手機版面測試涵蓋 320×568、390×844、430×932、桌機直式容器及 390×500 短視窗；這不是實體 iPhone／Android 安裝驗收。跨日與原版全部分支另有純狀態測試。
