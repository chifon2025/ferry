# 渡 · 順流成真
## 一盞燈的旅程

公開網站：[渡](https://chifon2025.github.io/ferry/)。沿用既有 GitHub Pages、PWA 身分與安裝入口。2026-09-19 起，新主線取代花店日記。

### 主線與玩法

以使用者提供的原創《順流成真・一盞燈的旅程》為骨架，創作可遊玩的生活事件。不是宗教測驗、古籍引文或萊斯特生平改編；不把故事中的光當成科學或療效宣稱。

十二章依序為：來到世界、習慣、與自然相處、鏡子裡的我、逍遙、良知、知而行、兩種力量、兩條路、回到生命、最後的鏡子、順流成真。另有序章與尾聲。

每章兩張行動牌，各接兩張後續選擇，共 48 條有獨立結果的路線。點牌先看做法，確認才推進；每章兩次選擇後進入收尾。沒有重複選心願、抽牌等候或情緒評分。不同做法帶來具體不同的後續，但不把一條路標成唯一正解。

- 「照一照心裡」看見該章想要與不想要，沒有必答題。
- 「往後看看」保留使用者提出的十年視角，不否定持續的影響。
- 兩種探索皆可略過，返回保留待確認的選牌，不寫入感受、不影響外部結果。
- 生氣、害怕時燈仍亮著；亮度不反映表現，也無成就或修行等級。
- 「回到生命」是虛構的村莊修繕事件，不發布使用者的個人財務資料。
- 結尾可接下一章、重走當章或暫停；十二章可從選單任選，沒有解鎖門檻。
- 不保證心願實現或情緒改善；不要求放棄醫療、安全、責任、人際界線。

### 手機畫面與視覺

固定直式單屏，最大寬 480px、高 100dvh，使用安全區。故事依閱讀區實際容量無損分頁，不縮字、不省略正文；字體與視窗大小改變時重新分頁。功能選單可獨立捲動。

以程式原生 SVG 山水、村落、鏡面與提燈搭配紙頁；五組景色隨章節切換，無外部字體與圖片依賴。沒有新增水聲、配樂或持續動畫。橫向與小螢幕會減少景物所占空間，把文字與操作留在畫面內。

### 存檔與更新

新主線只讀寫 `du_ferry_light_v1`，格式為 v:1，保存章節、階段、兩次已確認的行動。既有 `du_ferry_cards_v1`、更早遊戲紀錄及聲音設定都不讀寫，不強制遷移，不清空儲存空間。

無法辨識、空值、損壞或未來版存檔不覆寫；禁用儲存或容量不足仍可暫時試玩。跨分頁先比較原始資料，衝突需先讀取最新進度。未確認的選牌、閱讀頁碼與暫時探索只留記憶體。

服務工作程式 `light-v2` 完整快取 12 個新主線資源，移除本網站過期快取但不碰存檔。保留開啟、回前景、重新連線與選單檢查更新；花店資源不再載入、不再離線快取。舊卡牌程式留作歷史回歸測試，不是現行入口。舊網址 boat.html、legacy.html 仍導向首頁。

### 開發與驗證

純靜態，無需建置或安裝正式執行相依。開發：`node tools/serve.js . 8138`。自動測試：`node --test tests/*.test.cjs`。

`light-story.js` 為內容、`light-core.js` 為純狀態轉移、`light.js` 為介面、`light.css` 為新版畫面。沿用 `cards-layout.js` 無損分頁與 `pwa-update.js` 更新流程。

選用的 `tools/light-browser-check.cjs` 以獨立無頭瀏覽器檢查手機尺寸、放大字體與操作區；需已安裝 Playwright，可透過 FERRY_PLAYWRIGHT_PATH 指定位置，預設使用 Edge。這不等於實體 iPhone、Android 安裝或使用成效驗收。

本次驗證：56 項單元／介面模擬／離線快取測試通過；無頭 Edge 完成 578 次版面與操作狀態檢查，涵蓋 320×568 至 768×1024、橫向 844×390，以及 150%、200% 文字尺寸。`tools/light-offline-check.cjs` 另驗證實際離線重載、離線選牌、舊入口導向與舊資料保留。實體手機安裝仍待真機確認。

手機底部裁切修正：主畫面以 visualViewport 與 innerHeight 的較小有效高度同步，底部操作獨立成一區，故事區使用可收縮的網格列。工具列、轉向、前景恢復時重新分頁，雙指縮放不重算成更小的排版。`tools/light-mobile-check.cjs` 在手機觸控模式及可視高度變動下檢查 60 個狀態；原版在模擬可見 620px、頁面 844px 時確認鍵落到 815px，修正版已通過。實際使用者裝置尚待回報。
